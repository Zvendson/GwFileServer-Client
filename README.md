# GW FileServer Client

A simple tool to download files from Arenanet (guild wars) file servers.
The tool currently only downloads both GW executables. I am not quite sure why they have 2 different but it seems that the American region has its own.
Atleast my US friends sent me a different Gw.exe than my EU friends had.

Just pick the Gw.exe whatever size is closest to your exe. The "worst" case is that the exe updates itself to the proper Gw.exe. Too lazy to reverse the exact reason and dont really care.

## Installation

1. clone the repo
2. install [python](https://www.python.org/downloads/) if not already done
3. Run `scripts/Setup.bat`
4. Open `GWFileServer.sln`
5. Switch to Release and build the project
6. Run it.
